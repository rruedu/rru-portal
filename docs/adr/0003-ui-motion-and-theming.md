# 3. Dual Theme and Adaptive Radial Orbit Navigation

We decided on a dual-theme visual design (defaulting to a Dark Violet-Pink cyber-glass aesthetic with a toggleable Clean Light Pastel mode). The desktop hero section features an interactive central school emblem with orbiting department nodes that burst-expand into service cards, while dynamically adapting to a thumb-friendly arc carousel on mobile viewports. This balances high visual impact with practical touch usability.
