# 5. Mobile Adaptive Bento Hero and Developer Attribution

We decided to bifurcate the home view presentation across device form factors:
1. **Desktop/Tablet**: Preserves the 360-degree Radial Orbit visualization celebrating the circular gateway aesthetic.
2. **Mobile (< 640px)**: Adopts a vertical Smart Adaptive Hero pairing a central glowing school emblem with five thumb-optimized Bento Action Cards. This replaces the awkward circular squeezing on tall narrow screens with instant, one-tap thumb accessibility.

Additionally, the portal header adopts a two-row mobile layout for comfortable touch typing, and the footer integrates prominent attribution crediting Portal development to Teacher Trairat Chanmas under Rattharat Upatham School, Secondary Educational Service Area Office Ratchaburi (สพม.ราชบุรี).
